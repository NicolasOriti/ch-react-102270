CICLOS DE VIDA DE REACT

Tres Fases en un componente de REACT

Fase de montado --- Cuando se pinta el componente en la UI
Fase de actualizacion --- cuando se actualiza el estado del componente
Fase de desmontado --- Se remueve el componente de la UI

useEffect usamos para emular ciclos de vida en REACT

useEffect(CALLBACK(), [arrayDeDependencias])


  useEffect(() => {
    console.log("USEEFFCT");
  }); // ESTE USEEFFECT SE EJECUTA EN LA FASE DE MONTADO Y DE ACTUALIZACION DEL COMPONENTE

  useEffect(() => {
    console.log("USEEFFCT");
  }, []); // ESTE USEEFFECT SE EJECUTA EN LA FASE DE MONTADO
